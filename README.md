# Grible Station / xDarkSpeed

Ресурсы Grible Station, исходники панели SS14.Admin и вспомогательные скрипты.

## Содержимое

- `Server/Resources` и `Client/Resources`: игровые ресурсы из локального проекта.
- `Server/RobustToolbox` и `Client/RobustToolbox`: имеющиеся ресурсы движка.
- `Admin/source`: имеющиеся исходники панели администрирования.
- Скрипты `.bat` и `.ps1`: запуск исходной локальной установки Windows.

## Важные ограничения

Это не полный набор исходников игрового сервера. В предоставленной папке игровые Client и Server представлены готовыми сборками и ресурсами; проекты C# игрового сервера отсутствуют. Для сборки версии Linux нужны соответствующие исходники игры и движка либо совместимая готовая сборка Linux.

Скомпилированные файлы, архивы клиента, PostgreSQL, базы игроков, резервные копии и приватные настройки не публикуются. Поэтому запуск из одного клона репозитория пока не поддерживается. Исходники панели также ссылаются на отсутствующие здесь скомпилированные библиотеки игры в `Admin/source/lib`.

Оригинальная локальная установка сохранена отдельно. Пароли и OAuth-секреты должны храниться только в локальных конфигурациях, исключённых через `.gitignore`.
